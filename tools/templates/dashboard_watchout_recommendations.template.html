🔄 How to Refresh Dashboard with New Data

The dashboard loads data once when the page opens. To see updated source files, you need to rebuild the embedded dashboard.

Step 1: Run the Update Command

Open PowerShell in the source/ folder and run:

.\update_dashboard.ps1
Step 2: Wait for Build to Complete

The script will:

  • Sync source files to runtime data
  • Process CSV/JSON files
  • Regenerate the embedded dashboard HTML
Step 3: Reload Dashboard

Once complete, reload your browser (Ctrl+F5 for hard refresh) to see the updated data.

💡 Tip: The watcher script (watch_refresh_dashboard.ps1) can automatically rebuild when you change source files. Start it with:
.\tools\watch_refresh_dashboard.ps1 -SkipMissingDataReport
